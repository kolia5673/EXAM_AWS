AI Image Service



Вебзастосунок на ASP.NET Core MVC для завантаження зображень та їх аналізу за допомогою Gemini API.



Можливості



\- Завантаження зображень через вебінтерфейс.

\- Аналіз зображень за допомогою Gemini API.

\- Збереження зображень у Amazon S3.

\- Збереження результатів аналізу в PostgreSQL.

\- Перегляд історії аналізів.

\- Розгортання на Amazon EC2.



Технології



\- C# та ASP.NET Core MVC

\- Entity Framework Core

\- Google Gemini API

\- Amazon EC2, S3 та RDS PostgreSQL

\- Nginx та systemd



Демонстрація



http://18.195.121.89



Налаштування



Для роботи застосунку потрібно налаштувати API-ключ Gemini, рядок підключення до PostgreSQL та параметри AWS.



Зберігайте секрети у змінних середовища або захищеному сховищі. Не додавайте ключі та паролі до репозиторію.
